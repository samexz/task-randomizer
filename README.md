# Secret Task Picker

A simple web app to assign tasks fairly using a hidden number system.

## Live
https://samexz.github.io/task-randomizer/

## How it works
- Enter number of members  
- Add tasks (one per line)  
- Each person picks a number  
- Tasks are revealed at the end
